Sensor setup guide

I2C 400kHz Protocol

MAX30102 PULSE OXIMETER

  • VIN: 3.3V (Regulated)
  • GND: ESP32 Common Ground
  • SDA: GPIO 21 (Default I2C Data)
  • SCL: GPIO 22 (Default I2C Clock)
  • INT: GPIO 19 (Optional Data Ready)

NTC SKIN TEMPERATURE SENSOR

  • VCC: 3.3V
  • SIGNAL: GPIO 34 (ADC1 Analog In)
  • RESISTOR: 10kΩ Voltage Divider

MPU6050 6-AXIS IMU (ACTIGRAPHY)

  • SDA: GPIO 21 (Shared I2C Bus)
  • SCL: GPIO 22 (Shared I2C Bus)
  • I2C Address: 0x68
